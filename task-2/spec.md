# Специфікація вимог: Маркетплейс (Завдання 2)

## 1. Намір (Intent)
Формалізувати функціональні вимоги до мультивендорного маркетплейсу, побудувати сценарії використання (Use Cases) і забезпечити трасованість вимог до сутностей даних із Завдання 1 (`USER`, `STORE`, `CATEGORY`, `PRODUCT`, `ORDER`, `ORDER_ITEM`, `REVIEW`).

## 2. Сутності та ключові кроки
- **Сутності (ERD Завдання 1):** `USER`, `STORE`, `CATEGORY`, `PRODUCT`, `ORDER`, `ORDER_ITEM`, `REVIEW`.
- **Оформлення замовлення:** покупець підтверджує кошик → створюється `ORDER` у статусі `Pending` → створюються `ORDER_ITEM` із `unit_price` → резервується `PRODUCT.stock_quantity`.
- **Оплата (необов'язкова):** онлайн-оплата через `Payment Gateway` → `ORDER` стає `Paid` або, при відмові, `Unpaid` із поверненням резерву.

## 3. Актори (Actors)
- **Людина:**
  - `User` — абстрактний базовий актор.
  - `Customer` (успадковує `User`) — шукає товари, оформлює замовлення, залишає відгуки.
  - `Seller` (успадковує `User`) — керує `STORE` і `PRODUCT` власних магазинів.
- **Зовнішня система:** `Payment Gateway` — обробляє онлайн-транзакції та повертає статус оплати.

## 4. Критерії прийняття (Acceptance Criteria)
1. **Формат EARS:** усі вимоги (EARS-01..10) записані за синтаксисом EARS.
2. **Зв'язок з ERD:** кожен Use Case прив'язано до сутностей ERD.
3. **Модель Use Cases:** генералізація `Customer`/`Seller` → `User`; `<<include>>` для фіксації ціни (`ORDER_ITEM.unit_price`); `<<extend>>` для опціональної оплати.
4. **Трасування:** матриця N:M між EARS та Use Cases; щонайменше одна вимога (EARS-07) у Out of Scope з обґрунтуванням.
5. **Seller:** `UC_ManageStore` і `UC_ManageProduct` покриті EARS-08..10; зміни чужих `STORE` і `PRODUCT` відхиляються.
6. **Однозначність (результат аудиту EARS):**
   - резерв товару — це зменшення `PRODUCT.stock_quantity` на `ORDER_ITEM.quantity`, скасування — повернення цієї кількості;
   - оцінка `REVIEW.rating` — ціле число від 1 до 5.
7. **Рендеринг:** Mermaid-діаграма відображається на GitHub без помилок у компактній вертикальній орієнтації.
