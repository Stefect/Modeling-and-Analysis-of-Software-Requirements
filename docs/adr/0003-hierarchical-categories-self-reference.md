# 3. Моделювання ієрархії категорій через рекурсивний зв'язок (Adjacency List)

* Статус: прийнято
* Дата: 2026-09-15

## Контекст та постановка проблеми
Маркетплейс вимагає створення багаторівневого каталогу (наприклад: *Електроніка -> Смартфони -> Аксесуари*). Потрібно обрати спосіб зберігання категорій з довільним рівнем вкладеності.

## Розглянуті варіанти
* **Варіант 1:** Створення жорстких таблиць для кожного рівня (`CATEGORY`, `SUBCATEGORY`, `SUB_SUBCATEGORY`).
* **Варіант 2:** Патерн Adjacency List — рекурсивний зв'язок сутності `CATEGORY` на саму себе через `parent_id`.

## Рішення
Обрано **Варіант 2** — рекурсивний зовнішній ключ `CATEGORY.parent_id -> CATEGORY.id`.

### Позитивні наслідки
* Необмежена глибина вкладеності підкатегорій в єдиній таблиці.
* Дотримання 3NF без створення надлишкових таблиць-дублікатів.

### Негативні наслідки
* Вибірка повного дерева категорій вимагає рекурсивних запитів (CTE).
